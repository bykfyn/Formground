Pilot built locally · not deployed

Built & tested (staged at ~/code/archframe, no git repo yet)

  • Real scraper for Interior Cluster's Underleverantör section — robust `data-medlemstyp` attribute, not name-guessing
  • 30 real production partners scraped (29 with a real link, 27 with a real photo)
  • Real multi-area and missing-data edge cases handled correctly (tab-separated areas, shared placeholder image detected and excluded)
  • Static browse-only page generated and verified in-browser — echoes Formground's card format, separate code
  • Buyer-agnostic data model (per the shared production-partner decision) and `noindex` set, same caution as Formground's own /search.html

Sheerd

Narrative umbrella only

The shared vision across everything above — not a product itself, and not (for now) a shared technical domain. Sheerd.com is owned and free to use as Archframe's placeholder home, but Formground and Archframe stay on separate domains until one product actually proves itself. Umbrella branding and shared hosting are being treated as two separate decisions on purpose.
